# 智慧優先注音

[![Windows checks](https://github.com/sakiwatashi/keyinput123/actions/workflows/windows.yml/badge.svg)](https://github.com/sakiwatashi/keyinput123/actions/workflows/windows.yml)

以 PIME 與 libchewing 為基礎、操作方式接近微軟注音的 Windows 繁體中文輸入法。
它保留逐字編輯的手感，同時使用常用詞庫與個人學習資料改善選字。

**→ [下載最新版本](https://github.com/sakiwatashi/keyinput123/releases/latest)**

## 下載與安裝

1. 到 [Releases](https://github.com/sakiwatashi/keyinput123/releases/latest) 下載
   `Smart-Priority-Bopomofo-Setup-0.8.4.exe`（頁面上的 `SHA256SUMS.txt` 可用來核對檔案）。
2. 執行安裝程式，允許系統管理員權限。Windows 若跳出 SmartScreen 警告，按
   「其他資訊 → 仍要執行」。
3. 安裝完成就能用：它會排在繁體中文鍵盤清單第一位並設成預設輸入法，
   `Alt+Shift` 切回繁體中文時就會選到它。

電腦沒有 PIME 時，安裝程式會一併裝上包內已驗證數位簽章的 PIME 1.3.0；已經有
PIME 則保留現有版本，不會降版。首次安裝 PIME 時會隱藏隨附的「新酷音」，只留下
智慧優先注音；原本就有 PIME 的電腦不會動到既有的新酷音。

**更新**：下載新版安裝程式直接執行即可，個人學習資料會保留。

**移除**：Windows「設定 → 應用程式 → 已安裝的應用程式」解除安裝「智慧優先注音」。
只移除這個輸入法，不移除共用的 PIME，也不刪除個人學習資料。

## 特色

- **鍵位與微軟注音相同（大千）**，打完一個音自動選字，不必每字按空白。
- **整句一起判斷**：看前後文挑詞，「我試了一下」不會變成「我是了一下」，
  「這座城市」不會變成「蔗作城市」。
- **會學你的用法**：選過的字詞下次優先出現，而且分場合記——在「寫」後面選過
  「程式」，不會讓「這座城市」也變成「這座程式」。
- **注音可以不照順序打**：先打 `ㄧ` 再補 `ㄒ` 一樣得到「信」；「下一步」「因為」
  這類連打也不會掉字。
- **整段都能改**：還沒送出的文字可以移游標回去改任何一個字。
- **自動完成**：常打的句子打到一半會提示後半段，按 `Tab` 接上。
- **常見錯字自動修正**：「以經→已經」「迫不急待→迫不及待」等；你親自選定的字不會被改掉。
- **輸入法本身不連網、不上傳**：所有學習資料只存在你自己的電腦。

選字的運作方式與實測數字見文末〈[選字怎麼運作](#選字怎麼運作)〉。

## 基本操作

| 按鍵 | 作用 |
|---|---|
| 打注音 | 打完一個音自動選第一候選 |
| `↓` | 開啟候選；左欄 `1–5`、右欄 `6–0`，按數字選字，也可用滑鼠點選 |
| `→` | 候選下一頁 |
| `←` `→`（組字時） | 移動游標，改句子中間的字 |
| `空白` | 單獨一個注音時補上一聲（`ㄧ→一`）或開啟候選 |
| `Enter` | 送出畫面上的文字 |
| `Backspace` / `Del` | 刪游標左邊／右邊那一格，下一個注音補進原位置 |
| 短按 `Shift` | 切換中英文 |
| 按住 `Shift` + 字母 | 暫時輸入英文，不切換模式 |
| `Tab` | 接上自動完成的提示（沒有提示時照常交給應用程式） |
| `Esc` | 收掉自動完成提示 |

中文標點用 `Ctrl`，中英文模式都能用：

| 按鍵 | 輸出 | 按鍵 | 輸出 |
|---|---|---|---|
| `Ctrl+,` | `，` | `Ctrl+Shift+;` | `：` |
| `Ctrl+.` | `。` | `Ctrl+Shift+/` | `？` |
| `Ctrl+'` | `、` | `Ctrl+Shift+1` | `！` |
| `Ctrl+;` | `；` | `Ctrl+[` / `Ctrl+]` | `「` / `」` |
| | | `Ctrl+Shift+[` / `Ctrl+Shift+]` | `『` / `』` |

`Shift` 加數字或符號鍵一律輸出標準 ASCII 符號（`!`、`@`、`<`、`?` 等）。
右側數字鍵盤永遠直接輸出數字與 `/ * - + .`。沒有正在組字時，直接按 `3`、`6`、
`4`、`7` 會輸出聲調符號 `ˇ`、`ˊ`、`ˋ`、`˙`。

## 控制台

開始選單「智慧優先注音 → 智慧優先注音 控制台」。六個分頁：

- **狀態** —— PIME、候選視窗輔助程式是否執行，輸入法版本與安裝位置，以及
  行程外候選視窗、自動完成的開關。
- **個人詞庫** —— 檢視、搜尋、修改、刪除學到的詞與排名鎖定。執行中的輸入法
  會用記憶體內容覆蓋整個檔案，所以儲存鍵會一併重啟 PIME。
- **使用說明** —— 操作規則與中文標點對照表。
- **候選字過濾** —— 決定哪些字不要出現在候選單（見下節）。
- **同步** —— 在兩台電腦之間合併詞庫（見〈[在兩台電腦之間同步](#在兩台電腦之間同步)〉）。
- **按鍵配置** —— 自訂每個注音符號在哪個鍵上（見〈[自訂鍵位](#自訂鍵位)〉）。

### 候選字過濾

冷僻字會佔掉候選欄位，拖慢選字。台灣字頻分不出「冷僻沒用」和「冷僻但想要」：
`恣` 是 5 分而 `祐` 只有 1 分，`昕` 與 `彤` 是 0 分卻和 `眥`、`剚` 同級。純手動
挑選也不行 —— 把 `ㄗˋ` 的 `孳 恣 磧 眥 剚 胔` 藏起來之後，`胾 扻 倳 牸 芓 絘`
會立刻從後段遞補上來。因此提供三種設定，優先序由高到低：

| 設定 | 作用 |
|---|---|
| 一律保留 | 不論如何都顯示，用來救門檻誤殺的字 |
| 一律隱藏 | 逐字勾選 |
| 字頻門檻 | 低於此分數一律隱藏；`0` 為關閉（預設） |

門檻 7 的實測：`ㄗˋ` 由十個候選收斂為「字 自 漬」，`ㄉㄜ˙` 收斂為
「的 地 得 底」，`ㄕˋ` 完全不變。隱藏對整句組字也有效。

**這是隱藏，不是刪除。** 內建字典完全沒動，把設定清掉就全部回來。若某個讀音
的候選被全部隱藏，系統會保留原本的清單，以免那個音打不出來。設定存於
`%APPDATA%\PinnedBopomofo\hidden-characters.json`。

### 自訂鍵位

「按鍵配置」分頁可以改每個注音符號落在哪個鍵上，存檔會一併重啟 PIME
（輸入法只在啟動時讀鍵位）。「還原為大千」回到內建配置。

配置存在 `%APPDATA%\PinnedBopomofo\keymap.json`，格式是「按鍵 → 注音符號」，
也可以直接手改：

```json
{ "name": "我的配置", "keys": { "1": "ㄅ", "q": "ㄆ" } }
```

**打不出所有注音的配置會被拒絕**，同一個鍵對到兩個符號也會被擋下，並指出是
哪個鍵。手改壞的檔案會讓輸入法退回內建大千，開啟「按鍵配置」分頁就會看到原因。

## 個人資料

全部存在 `%APPDATA%\PinnedBopomofo\`，都可以直接備份：

| 檔案 | 內容 |
|---|---|
| `pins.json` | 單一讀音的優先字 |
| `phrases.json` | 從你確認過的文字學到的詞語 |
| `contexts.json` | 某個讀音**接在哪個字後面**時你選了什麼 |
| `word_usage.json` | 你自己的詞頻表 |
| `pairs.json` | 你送出的文字裡哪兩個字常連在一起 |
| `usage.json` | 你送出過的文字與使用次數 |
| `completions.json` | 自動完成用：送出過的句子與次數 |
| `hidden-characters.json` | 候選字過濾設定 |
| `keymap.json` | 自訂鍵位（沒改過就沒有這個檔） |
| `feedback.json` | 轉換錯誤回報紀錄 |

`usage.json`、`pairs.json`、`completions.json`、`feedback.json` 都含有你實際打過的
內容，**不要上傳給別人**。刪掉 `completions.json` 只會讓自動完成提示歸零。

寫入採原子替換；若檔案意外損壞，輸入法會把原檔改名為 `*.corrupt-日期時間.json`
後以空資料啟動，不會因此整個失效。

輪替備份（從原始碼資料夾執行）：

```powershell
.\tools\backup_user_data.ps1          # 備份一次並輪替
.\tools\backup_user_data.ps1 -List    # 列出現有備份
```

### 在兩台電腦之間同步

備份做的是快照與還原，還原會整份覆蓋。桌機與筆電共用詞庫要的是**合併**：
在控制台「同步」分頁挑一個共用資料夾（OneDrive、Dropbox、隨身碟都行），先按
「試跑」看會變什麼，再按「合併並重啟 PIME」。每台電腦各做一次就會一致。

合併是相加的：任何一邊有的詞都會保留。同一個讀音在兩台電腦上被記成不同的字時，
依實際使用次數決定，並逐條列出保留與捨棄了什麼。次數類的檔案取兩邊的較大值，
重複同步不會讓數字膨脹，放進排程重複執行也安全。這個工具不上傳任何東西，只讀寫
你指定的資料夾。

命令列版本（適合排程）：

```powershell
python tools\sync_user_data.py --folder D:\OneDrive\PinnedBopomofo
python tools\sync_user_data.py --folder D:\OneDrive\PinnedBopomofo --dry-run
```

> 命令列版本在 PIME 執行中時會拒絕合併：執行中的輸入法會用記憶體內容覆蓋
> `phrases.json`，合併結果會在下次選字時被無聲蓋掉。控制台的分頁沒有這個限制，
> 它合併完會重啟 PIME。

同步的檔案是 `phrases.json`、`pins.json`、`usage.json`、`hidden-characters.json`、
`contexts.json`、`word_usage.json`、`pairs.json`、`completions.json`。
`keyevent-trace.json` 與 `candidate-ui.json` 刻意排除：前者是診斷資料，後者描述的是
這台電腦而不是使用者。

## 轉換錯誤回報工具

輸入法只在你明確改選候選字或詞時，把「注音、原轉換、改選結果」記錄在
`%APPDATA%\PinnedBopomofo\feedback.json`。不記錄前後句、應用程式名稱或身分資料，
也不會自動上傳。從開始功能表「智慧優先注音」開啟「轉換錯誤回報工具」，可以逐筆
編輯、移除、匯出，或在確認後建立 GitHub 回報。

## 遊戲與候選框外觀

日式直向候選框由**獨立行程**繪製，不塞在載入到每個應用程式的 TSF DLL 裡。所以
所有程式（含遊戲）行程內始終只有 PIME 原廠簽章 DLL，不會因為未簽章模組被反作弊
強制卸載而讓遊戲崩潰。輔助行程偵測到前景是防作弊遊戲時會停止服務，交還原廠
候選框。此功能預設開啟；要改回原廠候選框，在
`%APPDATA%\PinnedBopomofo\candidate-ui.json` 設定 `{"enabled": false}` 後重啟 PIME。

啟用輸入法、切換輸入框時不會強制改寫應用程式的 TSF 開關；遊戲、密碼欄位或明確
停用輸入法的控制項可保持關閉，避免反覆開關造成凍結。

全新安裝預設保留 PIME 原廠簽章 DLL。只有明確接受遊戲／反作弊相容性風險時，才從
原始碼執行 `.\install.ps1 -EnableUnsignedNativeUi` 把日式外觀改成直接載入 TSF DLL 的舊做法；這項選擇會保存
在本機，後續更新都會沿用。要切回原廠簽章版（例如英雄聯盟等遊戲無法輸入中文、
Shift 無法切換時），執行 `.\install.ps1 -DisableUnsignedNativeUi`。檔案正被 TSF 使用
時，切換會排程到下次重新啟動 Windows。

新版候選框只在 PIME 沒有其他輸入法模組時套用；安裝前會備份原始 PIME DLL，解除
安裝時安全還原。備份與待更新狀態存放於
`%ProgramData%\SmartPriorityBopomofo\native-state`，所以從 EXE 或原始碼安裝都能由
解除安裝程式正確辨識。

## 選字怎麼運作

給想知道細節的人。

- **注音順序與音節邊界**：聲母、介音、韻母與聲調可用任意順序輸入。「一」這種只有
  介音的字連著打就好——`下一步`、`一樣`、`一個`、`因為` 一路打完都正確。兩者的按鍵
  完全相同，靠兩個訊號分辨：合出來的音節國語沒有（`ㄍㄧ`）就開新音節；已經填好的
  欄位被覆寫（`ㄧ` 上面蓋 `ㄨ`），代表被蓋掉的那個是已經打完的字。
- **單字候選**：先保留讀音字典的首選，再以台灣字頻整理後續候選，避免全域高頻的
  多音字蓋過正確讀音，例如 `ㄩㄣˋ` 先出「運」而不是通常讀作 `ㄩㄢˊ` 的「員」。
  `ㄉㄜ˙`、`ㄗㄨㄛˋ`、`ㄕˋ` 的預設第一候選固定為「的、做、是」，只有你親自改選
  其他字時，個人學習才會暫時排在前面。「不」在 `ㄅㄨˋ` 中優先。
- **破音字的詞頻按讀音分開**：一般索引把一個字的**總**詞頻掛在它每一個讀音上，於是
  「還」的 286212 次（絕大多數唸 ㄏㄞˊ）同時壓在 `ㄒㄩㄢˊ` 上，打「玄」得到「還」；
  實測有 221 個讀音的第一名因此是錯的。改用多字詞的證據重新分配：`愛好`、`好奇`
  撐起 `ㄏㄠˋ`，一個詞都沒用到的讀音才壓到最低。
- **詞網格**：參考 libchewing、McBopomofo、Rime Essay 轉製的 113,738 條臺灣正體
  高頻詞，以及 178,148 條帶有明確注音的單字／詞語。整句同時比較所有切分方式與
  現代詞頻，不要求整句預先存在於字典；例如可組出「每／遇到／一句／新／句子」，
  而不是逐字輸出「美／譽／心」。文字權重只有在完整讀音吻合時才能改字，因此不會
  把 `ㄅㄟˋ ㄑㄩㄝˋ` 誤判成「貝殼」。
- **語言模型**：內建新酷音（libchewing-data）的雙詞語言模型，知道「了」接在「是」
  後面罕見、接在「試」後面常見。模型的詞頻不分讀音，套用前會依本專案按讀音拆開
  的詞頻分配。以使用者確認過的 889 句依序重打，手動選字從 748 次降到 546 次
  （每百字 13.6 → 9.9 次）。模型約 25 MB，執行時多用約 56 MB 記憶體；授權為
  CC BY 4.0，出處見 `THIRD_PARTY_NOTICES.txt`。
- **補上詞庫缺的組合**：「這座城市」原本打成「蔗作城市」——詞庫裡沒有「這座」，
  只有「蔗作」。指示詞加量詞是文法上能產的格位，64 組裡缺 21 組（`每個`、`哪個`、
  `這台`、`那次`…），已補上，且不覆寫上游已有的權重。
- **可見的修正**：組字時先用全句詞網格更新未鎖定文字，再以保守近音判斷與常用詞庫
  產生修正，讓「優仙→優先」「部合理→不合理」「音該→應該」直接成為畫面上的首選，
  不會等到按 `Enter` 才暗中變字。自動組字與候選視窗共用同一份排序；`Enter` 只提交
  畫面上已採用的文字。另有 46 條高可信錯字規則（`bopomofo_core/data/common_typos.json`），
  參考國家教育研究院用字分析、以教育部國語辭典核對；「的／得／地、在／再」與合法
  異形詞不做無條件替換。
- **候選視窗**：在句尾開啟選字時，先列完整句修正及游標附近的 2–12 字詞彙；游標移進
  句中後，先列游標右側的單字候選，同一頁保留詞語／整句候選。按 `1` 只鎖定正在
  編輯的音節並前往下一字；選詞語時一次更新整個詞。最多保留 20 個實用候選。
- **個人學習與上下文**：`phrases.json` 只回答「這個讀音變成了什麼」，不管它出現在
  哪裡，所以選過一次「程式」之後，「這座城市」會變成「這座程式」。`contexts.json`
  記左邊一個字：`座→城市` 和 `寫→程式` 都常見，`座→程式` 不常見。有上下文佐證時，
  你的選擇立刻生效；沒有佐證時，個人偏好只在候選勢均力敵時覆寫詞庫（「計畫／計劃」
  1.0 倍、「在做／再做」3.6 倍都算勢均力敵）。詞庫沒有的自造詞不受這條限制。
- **你的詞頻表**：`phrases.json` 沒有次數，用過五百次的詞和誤學一次的詞權威相同。
  `word_usage.json` 在送出時把文字切成詞各記一次，用到三次以上就排到內建詞庫前面。
  刻意記在**詞**上：「不」和「步」當成字是無解的歧義，當成詞（`不要`／`下一步`）
  讀音串不同，各自累積。`pairs.json` 記你打過的相鄰字，詞庫知道「一部」比「一步」
  常見，但只有你打過的字知道「走」後面你接的是「一步」。
- **自動完成**：至少打了兩個字當線索、後面接的內容累計出現三次以上才提示，而且只補
  大家都同意的那一段——打過兩次「謝謝您的協助」、一次「謝謝您的協助喔」，提示的是
  「您的協助」。它只提示、不改選字排序，可在控制台「狀態」分頁關閉。
- **大小寫與快速按鍵**：字母大小寫依鍵盤實際狀態決定，`Shift` 會反轉大寫鎖定。快速
  重疊按鍵有實體鍵碼備援，降低漏掉前一個注音的機率。送進 libchewing 查候選的鍵位
  永遠維持大千，不受自訂鍵位影響。

## 給開發者

```powershell
git clone https://github.com/sakiwatashi/keyinput123.git
cd keyinput123
.\install.ps1          # Git Bash 用 ./install.sh
```

兩個安裝腳本都從自身位置尋找檔案，專案路徑含空白、中文或放在其他磁碟都能用。

測試：

```powershell
python -m unittest discover -s tests -v       # 核心單元測試
.\tools\run_all_tests.ps1                      # 全部測試（含 CI 跑不到的）
.\tools\run_all_tests.ps1 -SkipSlow            # 跳過全讀音稽核
```

CI 只跑 64 位元的單元測試與 PowerShell 煙霧測試。真正驗到按鍵行為的兩支需要 PIME
內建的 32 位元 Python 才能載入 libchewing —— 改完 `pinned_bopomofo_ime.py` 一定要在
本機跑過：

```powershell
& 'C:\Program Files (x86)\PIME\python\python3\python.exe' .\tests\pime_adapter_smoke.py
& 'C:\Program Files (x86)\PIME\python\python3\python.exe' .\tests\pime_all_readings_audit.py
```

建置：

```powershell
.\build_pime_overlay.ps1    # PIME 模組覆蓋層
.\build_release.ps1         # 正式安裝包（需要 NSIS 3.12）
```

正式安裝包含解除安裝程式、SHA-256 雜湊及 PIME/libchewing 的第三方授權聲明。
安裝腳本記錄位於 `%ProgramData%\SmartPriorityBopomofo`。

從本機回饋產生**待人工審查**的規則建議（不會自動寫入詞庫）：

```powershell
python .\tools\suggest_from_feedback.py
```
